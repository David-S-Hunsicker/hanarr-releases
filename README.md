# Hanarr Releases

Public Windows installers, checksums, release metadata, and release notes for Hanarr.

## Download

Download the latest `Hanarr-Setup-*.exe` installer from the [latest release](https://github.com/David-S-Hunsicker/hanarr-releases/releases/latest). Verify the installer with its adjacent `.sha256` file before running it. Releases are unsigned, so Windows may show an unknown-publisher or SmartScreen warning.

The Hanarr application source code is not published in this repository.
